# KICKZ — Urban Streetwear Sneaker Landing Page ⚡👟

A high-energy, responsive e-commerce landing page built for modern sneakerheads and streetwear culture enthusiasts. Engineered with semantic **HTML5**, utility-first **Tailwind CSS**, and dynamic **JavaScript (ES6+)**.

## 🌟 Key Features

* **Urban Streetwear Aesthetic:** Deep dark palette (`#07090E`) with high-voltage neon lime green (`#CCFF00`) and electric orange accents.

* **Dynamic Hero Showcase:** 3D rotated sneaker presentation, dynamic price badge, geometric background accents, and quick-action CTAs ("Shop Now" & "Watch Film").

* **Featured Collection Grid:** Scalable sneaker catalog rendered dynamically with tags, wishlisting toggles, and direct "Add to Cart" triggers.

* **Streetwear Essentials & Promo Banners:** Asymmetrical editorial cards spotlighting limited-edition drops and global culture.

* **Trust & Value Proposition Bar:** Highlights key shopping assurances including Free Shipping (\$75+), 100% Secure Payments, and 30-Day Easy Returns.

* **Interactive Slide-over Cart Drawer:**

  * Real-time item additions and removals.

  * In-cart quantity modifiers (`+` / `-`).

  * Dynamic subtotal, conditional free shipping, and grand total calculations.

  * Smooth backdrop overlay and off-canvas slide animations.

* **Full Device Responsiveness:** Custom mobile drawer navigation and fluid layouts designed for mobile, tablet, and desktop screens.

## 🛠️ Built With

* **HTML5:** Semantic document architecture.

* **Tailwind CSS (CDN):** Utility-first styling with modern dark theme tokens.

* **JavaScript (ES6+):** Pure vanilla state management, DOM manipulation, and dynamic component rendering.

* **Google Fonts:** Plus Jakarta Sans for sharp, modern typography.
